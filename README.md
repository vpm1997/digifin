# DigiFinSaviour

GitHub Pages-ready static prototype for AI-powered financial consumer protection.

## Publish with GitHub Pages

1. Open repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.
6. GitHub will provide the Pages URL after deployment.

This version intentionally performs its demo analysis in the browser. It does not expose an Anthropic API key. For production Claude analysis, connect a secure serverless/backend endpoint later.
